# Share Browser Test Checklist

Record the operating system and browser version when completing this release check.

- [ ] iPadOS Safari, portrait: open a link from Messages or Mail, edit, reload, print, reshare, and add a copy to the Editor.
- [ ] iPadOS Safari, landscape: repeat the editable workspace, Web Share link, and `.stitch-project` file-share checks.
- [ ] Desktop Safari: open, edit, restore a draft, copy a link, print, download, and import a copy.
- [ ] Desktop Chrome: verify Web Share when available and clipboard fallback otherwise.
- [ ] Desktop Firefox: verify clipboard fallback, printing, downloading, and malformed-link errors.
- [ ] All browsers: opening a link leaves existing project autosaves unchanged until Add copy to Editor is selected.
- [ ] All browsers: an oversized project clearly offers a `.stitch-project` file instead of a link.
- [ ] All browsers: malformed, truncated, oversized, and unsupported links show localized errors without mounting the pattern grid.
